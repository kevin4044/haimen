# MQTT 鉴权启用与收尾步骤

实现：`HMAC-SHA256(auth_key, client_id)` 派生设备密码，broker 在 CONNECT 时重算比较。
控制主题 `haimen/ctl/` 只接受 `client_id == "haimen-admin"`。

## 为什么需要 grace 模式

固件**只在开机时拉 OTA**（`CheckNewVersion()` 在 `Start()` 里，见 `application.cc:386`），
MQTT 连不上也不会去重拉。所以直接开启 `auth_key` 会让在线设备立刻被拒，
只能靠人手断电恢复 —— 实测确认过（设备每 15 秒重试一次，全被拒）。

`auth_grace = true` 期间，静态 `password` 仍然有效，设备不会掉线。

## 当前状态

`~/works/haimen-data/settings.toml`：

```toml
[xiaozhi.mqtt]
username = "haimen"
password = "haimen"
auth_key = "<已生成>"
auth_grace = true     # ← 迁移期
```

## 收尾三步

1. **断电重启设备**（同时会把屏幕时间修正，因为只有开机才拉 OTA）
2. 确认设备已用派生密码连上：
   ```bash
   docker logs haimen-test --since 5m | grep "迁移期旧密码"
   # 没有输出 = 已经在用派生密码
   ```
3. 把 `auth_grace` 改成 `false`，然后
   ```bash
   cd ~/works/haimen && ./scripts/cd.sh --skip-ci
   ```

## 验证鉴权真的生效

```bash
# 应该被拒（0x04 认证失败）
python3 - <<'PY'
import sys; sys.path.insert(0,'scripts/xiaozhi_sim')
from mqtt_link import MqttLink
try:
    MqttLink('192.168.110.35', 1883, 'haimen', 'wrong', client_id='evil').connect()
    print('❌ 竟然连上了')
except Exception as e:
    print('✅ 已拒绝:', e)
PY
```

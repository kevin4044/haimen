# Emoji presets

These 21-emotion presets mirror the official Xiaozhi assets generator
(`78/xiaozhi-assets-generator`, MIT) and are bundled so haimen can offer the
same defaults without a network fetch to the official site.

- `twemoji64/`: Twemoji 64×64 PNG, 21 emotions.
  - Source: https://github.com/jdecked/twemoji
  - Graphics license: CC-BY 4.0 (see `TWEMOJI-LICENSE.txt`).
  - Copyright 2020 Twitter, Inc and other contributors.
- `noto-emoji_64/`: Noto Emoji 64×64 animated GIF, 21 emotions.
  - Source: https://github.com/googlefonts/noto-emoji
  - Font/emoji license: SIL Open Font License 1.1 (see `NOTO-EMOJI-LICENSE.txt`).
  - Copyright 2013 Google LLC.

Files are copied unchanged from:
https://github.com/78/xiaozhi-assets-generator/tree/main/web/public/static/emojis

The 21 emotion names are:
`neutral`, `happy`, `laughing`, `funny`, `sad`, `angry`, `crying`, `loving`,
`embarrassed`, `surprised`, `shocked`, `thinking`, `winking`, `cool`, `relaxed`,
`delicious`, `kissy`, `confident`, `sleepy`, `silly`, `confused`.
